# tailsurf

Alias for [`@tailsurf/client`](https://www.npmjs.com/package/@tailsurf/client), the TypeScript client for [tail.surf](https://tail.surf) live transcript streams.

`npm install tailsurf` and `npm install @tailsurf/client` provide the same API:

```ts
import { TsfClient } from "tailsurf";
```

See the [client package](https://github.com/s2-streamstore/tailsurf/tree/main/typescript/packages/client#readme) for documentation.
